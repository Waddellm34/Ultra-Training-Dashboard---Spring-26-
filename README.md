# Ultra 50 Training Dashboard

Personal training dashboard for a 20-week ultramarathon program.

## Live site
Deployed to Netlify.

## Local development
Open `index.html` directly in a browser, or serve the directory with any static server:
```
python3 -m http.server 8000
```

## Files
- `index.html` — main dashboard
- `kitchen.html` — recipe + pantry + shopping companion app
- `program.json` — 140-day program data

## Tech
Vanilla HTML/JS/CSS. No build step. No dependencies.
